# Z

记录日常与待办的 Web 应用，另带一个本地书架。**单文件、原生实现、数据不出本机。**

- 日历 + 待办（完成进度、72 小时回收站、常驻撤销、批量建单）
- 书架（上传 txt、站内阅读、阅读进度、编码自动识别）
- 页面内弹窗提醒（关闭页面即失效，不使用系统通知）
- 无账号、无登录、无云同步、无任何上传请求

## 快速开始

直接用 Chrome / Edge 打开 `当前版本/index.html` 即可使用待办功能。

书架需要本地 HTTP 服务（`file://` 协议下无法使用 File System Access API）：

```bat
服务器快速启动.bat
```

或手动执行：

```bat
python -m http.server 8000 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8000/当前版本/index.html`。

首次使用书架需要点击「选择 / 更换 book 文件夹」，手动授权一个本地目录用于存放 txt；网页不会自动读取磁盘。仅 Chrome / Edge 支持，Firefox 不支持。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `当前版本/index.html` | 最新版本，唯一需要运行的文件 |
| `当前版本/book/` | 书架存放图书的本地目录（个人数据，已 gitignore） |
| `版本备份/` | 历史副本目录（已停用，不入库；版本改由 git 管理） |
| `项目要求/` | 各版需求与改版问题记录 |
| `_selftest.js` | 自测脚本，用 Node 跑真实页面逻辑 |
| `服务器快速启动.bat` | 启动本地 HTTP 服务 |

## 数据与存储

- 待办、设置、阅读进度：浏览器 `localStorage`（`JSON.stringify` / `JSON.parse`）
- 图书正文：你自己选择的本地 `book` 文件夹
- 目录访问句柄：IndexedDB（仅存句柄，不存正文）
- 书架不计入 JSON 备份

**清除浏览器缓存会丢失待办与阅读进度**，请定期通过侧边栏「导出 JSON 备份」保存。回收站条目保留 72 小时，自首次删除起算。

## 版本约定

版本由 git 管理，**不再复制 HTML 副本备份**：

- `当前版本/index.html` 始终是最新版本，`APP_VERSION` 同步递增 0.1
- 每完成一次版本更迭，就提交并推送到 GitHub
- 提交信息以版本号开头，例如 `1.4: 书架支持按目录导入`
- 回溯旧版本用 git：`git log --oneline`、`git show <commit>:当前版本/index.html`

`版本备份/` 目录中已有的历史副本已停用且不入库，可安全删除。

## 自测

```bat
node _selftest.js
```

脚本用最小 DOM 桩执行 `index.html` 内的真实代码，覆盖日历、待办、批量建单、提醒、回收站、撤销、书架上传/阅读/删除与静态约束检查。
